# Security Policy

## Supported versions

The `main` branch is the actively maintained version of GridWise AI. Releases are research prototypes and should not be connected to operational systems without independent review.

## Reporting a vulnerability

Please do **not** disclose security-sensitive details in a public issue. Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If that option is unavailable, contact the maintainer through [the profile](https://github.com/hossiendehghan989) and include:

- the affected file, endpoint, or dependency;
- a minimal reproduction;
- the potential impact; and
- any suggested mitigation.

Please allow reasonable time for assessment before public disclosure. Do not include secrets, production data, or personal data in reports.

## Scope boundary

GridWise is a research prototype. The public demo, if deployed, must use synthetic or public data only. API keys and operational credentials must be supplied through environment variables and must never be committed.
